LinkLauncher を始める

LinkLauncher は、ファイル・フォルダー・Web ページを案件や種類ごとに整理して開く Windows 用リンクランチャーです。

起動する

ZIP をすべて展開し、展開先のフォルダーにある LinkLauncher.exe をダブルクリックしてください。ショートカットを作る場合は、この EXE へのショートカットを作成します。

.NET 10 Desktop Runtime がない場合

LinkLauncher はアプリにランタイムを含めない軽量配布です。ランタイムが見つからない場合は、.NET apphost の標準案内が表示されます。Microsoft 公式ページで .NET Desktop Runtime 10 の Windows x64 版を選んで導入し、LinkLauncher.exe をもう一度実行してください。

Microsoft 公式 .NET 10 ダウンロードページ

このアプリはランタイムのダウンロードやインストールを自動実行しません。選ぶ項目は「.NET Desktop Runtime 10」「Windows」「x64」です。

基本操作

  • Ctrl + Alt + Space でランチャーを表示します。
  • 通常の右クリックはそのまま使えます。右ボタンを押して上へ 70 px 以上動かし、1.4 秒以内に離すとランチャーを表示します。
  • 検索欄からリンクを絞り込み、Enter またはリンクのクリックで開きます。
  • × または Esc で隠します。終了するときはタスクトレイの LinkLauncher アイコンから「終了」を選びます。
  • ファイル・フォルダー・URL を画面へドラッグして登録できます。登録や整理は画面のボタンから行います。

データとライセンス

登録したリンクや設定はユーザーの %APPDATA%\LinkLauncher\library.json に保存されます。保存時に既存データのバックアップも作成します。登録先のパスや URL は個人情報を含む場合があるため、公開リポジトリには含めないでください。
