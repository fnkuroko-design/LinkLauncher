# LinkLauncher

案件・資料の種類ごとに登録したファイル、フォルダー、Web ページを素早く開く Windows 用リンクランチャーです。C# / WPF / .NET 10 で作られています。

現在の開発版は **0.1.0-dev.4** です。試作段階のため、正式リリース前の動作確認用としてお使いください。

## 主な機能

- 案件や資料の種類で階層整理し、カテゴリやリンクを追加・編集・削除できます。
- 初期画面は700×440（Windowsの表示倍率に応じて拡大）、一覧は32pxの単行です。左上の☰でカテゴリ欄をたたむと536幅に縮まります。ウィンドウの縁から大きさを調整できます。
- メモのあるリンクには▤印が付き、項目にマウスを約0.5秒重ねるとリンク先・カテゴリ・タグ・メモを表示します。長文メモはプレビューし、全文は編集画面で確認できます。
- 名前、リンク先、タグ、カテゴリ名を検索します。検索対象は現在の一覧範囲に沿い、カテゴリ選択中はそのカテゴリと子カテゴリ、全体では全リンク、お気に入りではお気に入り、最近では最近使ったリンクに絞ります。検索欄と結果表示で対象範囲を確認できます。全角・半角と英字の大文字・小文字をそろえて検索します。
- お気に入りと最近使ったリンクを表示します。Enter またはリンクのクリックで開けます。
- ファイル、フォルダー、HTTP / HTTPS の URL を登録できます。画面へのドラッグ＆ドロップ登録にも対応し、貼り付けたパスや URL の外側にある対応した引用符・山括弧は自動で取り除きます。
- JSON の読み込みと書き出しに対応します。
- 設定の「Windowsへのサインイン時に起動する」は既定でオフです。オンにすると現在のユーザー用に登録し、サインイン後は画面を前面に出さずタスクトレイに常駐します。
- Ctrl + Alt + Space で呼び出せます。設定ではマウスの呼び出し方を1つ選べます。既定はホイールボタンを押しながら、動かさず右ボタンを押す方法です。
- タスクトレイに常駐し、× または Esc で画面を隠せます。
- 常時のディスク走査やネットワーク通信をせず、登録済みデータをメモリ内で検索します。
- ライト・ダークの表示はWindowsの「アプリのモード」に自動連動し、起動中の切り替えにも追従します。

## 起動方法

1. 配布 ZIP をすべて展開します。
2. 展開したフォルダーの LinkLauncher.exe を実行します。
3. .NET 10 Desktop Runtime（Windows x64）がない場合は、.NET apphost の標準案内が表示されます。Microsoft 公式ページを開き、「.NET Desktop Runtime 10」の Windows x64 版を導入してから、LinkLauncher.exe をもう一度実行してください。

Microsoft 公式ダウンロードページ: https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0

配布物は Windows x64 の framework-dependent 形式です。アプリに .NET ランタイムは含めません。ランタイムのダウンロードやインストールは自動実行しません。

## 操作

- Ctrl + Alt + Space: ランチャーを表示します。設定から利用可能な別のキーに変更できます。
- 設定の「マウスで呼び出す」では、呼び出し方を1つ選択します。既定の「ホイールを押しながら右クリック」は、ホイールボタンを押したまま動かさずに右ボタンを押すと、すぐ表示します。「右ボタンを押しながら左クリック」は、右ボタンを先に押してから左ボタンを押すと表示します。組み合わせの順序は固定です。
- 組み合わせずに最初のボタンを離すと通常のクリックになります。押したまま 5 px を超えて動かすと、最初の押下位置から通常のドラッグへ戻ります。呼び出しに長押しは不要です。既定の設定は右ボタン単独の操作に介入しません。
- 「ホイールクリック」「マウスの戻るボタン」「マウスの進むボタン」は、それぞれ該当ボタンを押した時点で表示します。他のアプリで使う同じボタンの機能を置き換えます。「使わない」を選ぶとマウスからは呼び出しません。
- Enter またはリンクのクリック: 選択中のリンクを開きます。
- Esc または ×: ランチャーを隠します。アプリはタスクトレイに残ります。
- タスクトレイのメニュー: ランチャーの表示、設定、終了を選べます。
- 項目の右クリックまたは⋯: 開く、編集・カテゴリ変更、リンク先のコピー、登録の削除を選べます。アプリ自身の画面ではマウス呼び出しを認識しません。
- 設定の「Windowsへのサインイン時に起動する」: サインイン後にタスクトレイへ常駐させます。既定はオフで、状態はWindowsの現在ユーザー用スタートアップ登録から読み取ります。JSONを読み込んでもこの設定は変更されません。LinkLauncher.exeを別のフォルダーへ移した場合は、新しい場所から起動して設定を保存すると登録先を更新できます。Windowsのスタートアップ設定で無効にされている場合は、Windows側の設定が優先されます。

管理者権限で動く画面など、入力状態を安全に判断できない対象ではマウス呼び出しを認識しません。その画面ではショートカットで呼び出してください。マウス設定は他アプリの入力と重なる場合があり、すべてのアプリで干渉しないことを保証するものではありません。特に単ボタンを選ぶと、そのボタン本来の機能が他アプリで使えなくなります。

ソースリポジトリの [UI調査記録](docs/UI-RESEARCH-dev.2.md) と [dev.4の検証記録](docs/VERIFICATION-dev.4.md) に、設計判断と確認範囲を記載しています。

## ユーザーデータ

登録内容と設定は次の場所に保存されます。

    %APPDATA%\LinkLauncher\library.json

保存時は既存ファイルを .bak として保持します。登録先のパスや URL は個人情報を含む場合があります。ソースを公開するときもユーザーデータは含めず、JSON を共有する場合は内容を確認してください。

## ビルドと配布

Windows 上で PowerShell から次を実行すると、プロジェクトの Version を使って framework-dependent ZIP を作成します。

    ./scripts/Publish.ps1

成果物は artifacts/releases/LinkLauncher-v&lt;Version&gt;-win-x64/ と同名の ZIP、SHA-256 チェックサムファイルに出力されます。既存の同名成果物は上書きしません。ZIP の中身は展開後のフォルダー直下に並びます。GitHub Actions は push、pull request、手動実行でビルドし、Actions artifact として保存します。GitHub Releases への公開は自動化していません。
