# LinkLauncher v0.1.2-dev.8 検証記録

日付: 2026-10-10。Windows x64 / .NET SDK 10.0.204。

## 変更と受入範囲

- 右＋左の方式では、通常の物理右DOWN・MOVE・右UPを保留・再送せず通す。移動の5pxしきい値は呼び出し候補の解除だけに使い、ドラッグ開始を待たせない。通常の静止右クリックにも合成DOWN/UPを使わない。
- 右を押したまま左DOWNが成立すると、押下元・現在位置・キャプチャ先の照合後に標準のキャンセルを要求し、左DOWNと両UPを消費して従来の呼び出しを行う。照合・照会・通知要求に失敗した場合は通常入力を通す。
- 右DOWNで実行された操作の取り消し、およびWM_CANCELMODEに対応しない独自の押下状態の解除は保証できない。ユーザーはこの競合を了承している。通知の成功は相手の処理完了ではなく、通知途中の失敗は原子的に取り消せない。詳細は [INPUT-DESIGN-dev.8.md](INPUT-DESIGN-dev.8.md)。
- デスクトップ空白の左ダブルクリックを選択肢へ追加し、アイコンや他ウィンドウでは呼び出さない設計にした。Shell/MSAA照会はバックグラウンドで行い、マウス入力を抑止しない。
- カーソルが外へ出たら閉じる設定を追加した（既定オフ）。固定・設定などのモーダル・メニュー・並び替えの操作中は非表示を抑える。CLaunchからの参考範囲は [ACTIVATION-RESEARCH-dev.8.md](ACTIVATION-RESEARCH-dev.8.md)。
- 既存のenum値・設定・リンクデータを維持する。新設定がない旧JSONではHideOnPointerLeaveはfalse。ユーザーデータの置き換えや、PDF手書き・Codexのコード変更は行っていない。

レビューで、キャプチャ照会の失敗を「キャプチャなし」と扱っていた箇所を修正した。失敗時は通知せず通常入力へ戻す。正常な照会でキャプチャなしの場合とは別に試験した。また、先行右DOWNで外側クリック非表示を先に行うと呼び出しが逆に切り替わる点、フォーカス非表示をオフにしたとき新しい非表示設定まで無効になる点を修正した。

Release / win-x64ビルドは警告・エラーなしで成功した。Computer Use、検証目的のマウス入力生成、カーソル自動移動は行っていない。配布EXEの実起動・最終UI確認は未実施。

## 手動確認が残る範囲

静止押下の通知遅延、ドラッグ開始のカクつき、解放時のメニュー表示は別々に確認する。今回の自動確認を実機での改善報告に置き換えない。

1. PDF手書き0.6.8の破棄できる資料で、静止右押下で円がすぐ表示されるか、短い右ドラッグの開始に引っかかり・位置の跳びがないかを確認する。右＋左の呼び出し後は、右DOWNの消去・独自モードが残るかも制約の実例として記録する。
2. Codexの送信しない選択テキストで、移動しない右クリックのメニュー、および右＋左呼び出し後のボタン解放を確認する。
3. エクスプローラーの通常右クリックと、確認用ファイルの右ドラッグでメニューを確認する。移動・コピーは実行せずEscで閉じる。
4. 任意設定を試す場合は、デスクトップ空白のダブルクリックとアイコンの通常ダブルクリックを各1回確認する。カーソル退出の非表示は、メニュー／設定画面を使用中に閉じないことも少数の操作で確認する。

デスクトップ空白判定はShellのクラス構成とMSAAロールに依存する。アイコン非表示時や特殊なデスクトップ構成を含む全環境での動作を保証しない。全アプリでの入力互換性を検証したとは報告しない。

## 常駐版・データの保持

作業時の常駐版はdev.7配布フォルダー内のEXE（PID 26608）であり、停止・再起動・設定変更を行っていない。ユーザーデータ、スタートアップ登録先、完成済みの正式版とdev.1〜dev.7の成果物を保持した。

新版を実機で比較するときは、既存版をトレイから終了し、新しいフォルダーのdev.8を起動する必要がある。2版の同時起動は単一起動制御によりできない。旧版へ戻す場合はdev.8を終了し、元のdev.7 EXEを起動する。新しいデスクトップ呼び出しを選択した場合は、旧版へ戻す前に右＋左など旧版にもある設定へ戻す。旧版は新enum値を認識しない。

データは既定で共通の `%APPDATA%\LinkLauncher\library.json`。設定保存時は、有効なスタートアップの登録先も現在のEXEへ更新される。比較で設定を変更する場合は、事前にJSONと登録コマンドを控え、比較後に変更した設定と登録先を戻す。リンク編集を行ったJSON全体を古いコピーで上書きしない。今回、この比較操作は実施していないため復元操作もしていない。
