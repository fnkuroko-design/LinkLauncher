# LinkLauncher v0.1.2

正式リリース（2026-10-11）。v0.1.1以降の表示・入力処理の改善と、選択可能な呼び出し設定をまとめました。

## 変更

- 拡大率が異なるサブディスプレイで、ランチャー内のクリックが外側のクリックとして扱われる問題を修正しました。
- 「右ボタンを押しながら左クリック」の呼び出しを維持し、通常の右押下・移動・解放を保留や再送せずに処理します。右ドラッグ開始時の待ちや、カーソルの座標往復をなくしました。
- 呼び出し後に左クリックが効かなくなる問題、カーソル退出で閉じた直後の連続呼び出し、ボタンの最初のクリックを妨げる問題を改善しました。
- 呼び出し元のメニューを照合して閉じ、ランチャーへ前面と入力フォーカスを戻します。表示後の検索入力に追加クリックは不要です。
- デスクトップ空白のダブルクリックによる呼び出しを選べます。アイコンや他アプリ上のダブルクリックには反応しません。
- 「カーソルがランチャーの外へ出たら閉じる」を設定で選べます（既定はオフ）。固定中、設定画面・メニュー・並び替えの操作中は閉じません。

## 既知の制約

右＋左の呼び出しで元メニューが一瞬見えたり、スタートボタン上でごくまれに残ったりする場合があります。遅れて開くメニューを閉じる際に元画面を一瞬活性化してランチャーへ戻すことがあります。独自メニュー全般の抑止や、Windowsが拒否する前面化は保証しません。

右ボタンを押した時点で元アプリが実行する処理は、ランチャーの呼び出し時に取り消せません。管理者権限や異なるbitnessのアプリなどでマウス呼び出しを認識できない場合があります。設定で別のマウス操作を選ぶことができ、ショートカットも利用できます。

## 導入と更新

Windows x64と.NET 10 Desktop Runtime（Windows x64）が必要です。ランタイムはZIPに含みません。未導入の場合は[Microsoft公式ページ](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0)から導入してください。

旧版をタスクトレイの「終了」で閉じ、新しい場所へZIPを展開して `LinkLauncher/LinkLauncher.exe` を起動してください。データは `%APPDATA%\LinkLauncher\library.json` に保存され、引き継がれます。スタートアップを有効にしている場合は、新版の設定で「保存」を押して起動先を更新してください。

ZIPの全ファイルを `LinkLauncher/` にまとめ、ランタイム・診断ログ・ユーザーデータは含めません。独自コード・アイコン・入力補助DLLはMIT Licenseです。同梱の `THIRD_PARTY_NOTICES.md` と `licenses/DOTNET-LICENSE.txt` に第三者ライセンスを記載しています。
