# LinkLauncher v0.1.2 検証記録

日付: 2026-10-11。Windows x64 / .NET SDK 10.0.204。

## 正式版への移行

完成したv0.1.2-dev.9の実装を維持し、Versionを0.1.2、FileVersionを0.1.2.0へ更新しました。README、起動案内、正式版のリリースノートを整備し、完成済みの正式版・開発版・試作成果物を保持します。

本作業の機能コード変更はありません。正式版のpublish、ZIP内容・展開前後の一致、ライセンス・ランタイム設定・診断除去を確認します。入力の実機試験やComputer Useは繰り返しません。

## 引き継ぐ検証結果と制約

- dev.9の診断除去後に、入力状態の自動試験13/13、ActivationCompletionChecks 4/4が成功しています。これらは正式版の版番号変更後に再実行した結果ではありません。
- PDF手書き0.6.8での静止した右押下時の円表示、右ドラッグ開始時の引っかかり・位置跳びは、ユーザーの少数手動確認で問題なしと報告されました。
- Codexのテキスト選択後の静止した通常右クリックで、解放時のメニュー表示と選択保持は問題なしと報告されました。
- デスクトップ・ファイルアイコンでの連続呼び出し、タスクバー空白での呼び出し、クリック不要の検索入力、「リンクを追加」の最初のクリックも手動確認されています。
- 診断なしdev.9配布版の最終評価では、スタートボタン上で元メニューがごくまれに残るとの報告があります。既知の制約として正式版にも記載し、完全な抑止とは扱いません。

静止中の押下通知、ドラッグ開始、解放時のメニューを分けて評価しています。自動試験は実機操作の改善を証明するものではなく、全アプリ・全環境で検証したとは扱いません。押下時に元アプリが実行する操作の取消しや、独自メニュー全般、Windowsが拒否する前面化は保証しません。詳細は[dev.9検証記録](VERIFICATION-dev.9.md)、サブディスプレイの修正は[dev.7検証記録](VERIFICATION-dev.7.md)に保持しています。
