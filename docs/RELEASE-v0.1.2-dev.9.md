# v0.1.2-dev.9

右ボタンを押したまま左クリックして呼び出す操作を維持し、他アプリの通常右クリック・右ドラッグとの干渉を改善した開発版です。特定アプリの除外や呼び出しボタンの変更で回避する方式ではありません。

- 通常の右押下・移動・解放を保留/再送せず、ドラッグ開始位置への座標往復も行いません。
- 呼び出し後に左クリックが効かなくなる問題と、退出で閉じた後の連続呼び出しの失敗を改善しました。
- 受理した呼び出し元のメニューを閉じ、遅れて開くメニューでは必要に応じて元画面とランチャーの前面を往復します。検索入力のための追加クリックは不要です。
- 表示されたボタンの最初のクリックを古い活性化処理が妨げる問題を改善しました。

実機ではデスクトップ/アイコン、タスクバー空白/スタート、PDF手書き0.6.8、Codexの代表操作を少数確認しました。PDF手書きの静止押下時の円表示と右ドラッグ開始、Codexの静止右クリックメニューと選択保持はユーザーが正常と確認しています。全アプリ・全環境の検証ではありません。

スタートボタンでは3回中1回、元メニューが一瞬表示されてから閉じました。右押下時に元アプリが実行する操作の取消し、独自メニュー全般の抑止、Windowsが拒否する前面化は保証しません。管理者権限や異なるbitnessのアプリなどでは呼び出しが認識されない場合があります。

配布はWindows x64 / .NET 10 Desktop Runtimeが必要なframework-dependent ZIPです。ランタイム・診断ログ・ユーザーデータを含めません。ZIPのルートは`LinkLauncher/`です。旧版をトレイから終了し、新しいフォルダーから起動してください。設定と登録データは引き継がれます。旧スタートアップ先を更新する場合は新版の設定を保存してください。

詳細は[入力設計](INPUT-DESIGN-dev.9.md)と[検証記録](VERIFICATION-dev.9.md)を参照してください。GitHub公開の完了記録ではありません。
