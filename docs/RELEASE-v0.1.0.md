# LinkLauncher v0.1.0

初回正式リリース（2026-10-07）です。

## 主な機能

- リンクを階層カテゴリで整理し、選択中の一覧に絞って検索できます。お気に入り、最近使ったリンク、ドラッグ＆ドロップ登録、JSON入出力にも対応します。
- Ctrl + Alt + Space または選択したマウス操作ですぐ呼び出せます。組み合わせは2つ目のボタンを押すと作動し、長押しは不要です。
- ライト・ダーク表示はWindowsの「アプリのモード」に連動します。サインイン時の起動は設定可能で、既定ではオフです。
- 貼り付けたパスやURLの外側にある対応した引用符・山括弧を取り除きます。

## 必要環境

- Windows x64
- .NET 10 Desktop Runtime（Windows x64）

配布形式はframework-dependent ZIPで、.NETランタイムは含みません。未導入の場合は[Microsoft公式ダウンロードページ](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0)から「.NET Desktop Runtime 10」のWindows x64版を導入してください。

## 既知の制限

- マウス呼び出しは管理者権限の画面などで認識できない場合があります。また、他アプリの入力と重なることがあります。単ボタンを選んだ場合、そのボタン本来の機能は他アプリで使えなくなります。呼び出せない場合はショートカットを使ってください。
- 更新は手動です。旧版をタスクトレイから終了し、新しいZIPを新しいフォルダーへ全展開してから、新版の `LinkLauncher.exe` を起動してください。データと設定は `%APPDATA%\LinkLauncher\library.json` に保存されます。スタートアップを有効にしている場合は、新版の設定で「保存」を押して登録先を更新してください。
