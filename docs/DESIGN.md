# LinkLauncher 初版設計

## 目標
案件や資料の種類を軸に、登録したファイル・フォルダ・Webページを素早く開く。
階層をたどる操作と、選択中の範囲を検索する機能を同じ画面に集約する。

## v0.1.0-dev.1
- C# / WPF / .NET 10。外部UIライブラリなし。
- Windows x64のframework-dependent ZIP。ランタイムを同梱せず、未導入時は公式の導入ページを案内。
- 左側のカテゴリ階層、右側のリンク一覧、上部の検索欄。検索は選択中の一覧範囲を対象にする。
- お気に入り・最近使ったリンク。名前、リンク先、タグ、カテゴリ名の検索。
- 登録、編集、削除、カテゴリ追加・移動、ファイルやURLのドロップ。
- Ctrl + Alt + Spaceによる呼び出し。タスクトレイ常駐。
- ライト・ダークの表示はWindowsのアプリモードに自動連動。変更通知で追従し、タイマー巡回なし。
- 右ドラッグ上方向のジェスチャーを既定で有効。任意でCtrl + 右クリックも有効化。
- %APPDATA%\LinkLauncher\library.jsonへ保存。置換前バックアップ。JSON入出力。
- 初期サンプルは専用カテゴリ内。実ファイルを勝手に取り込まない。

## 軽量化
待機中はタイマー・全ディスク索引・ネット通信を使わない。
検索は登録データのメモリ内検索。画面表示時のみ一覧を更新する。
マウスフックは有効な呼び出し方法だけを処理し、ファイル入出力を行わない。
表示時間・メモリ・待機CPUは実測値と目標を区別する。

## v0.1.0-dev.2
- 初期700×440、左164、リンク行32＋間隔1の単行一覧。左欄をたたむと幅を164縮める。
- タイトルと常設説明を圧縮し、リンク先・タグ・メモはホバーで表示。メモありを▤で示す。
- ツリーの全展開固定をやめ、開閉状態をセッション内で保持。選択カテゴリの祖先は表示する。
- 操作メニューを右ボタン解放後に開き、リンク起動は同じ行での左押下・解放が揃う場合に限定。
- 右ジェスチャーの押下・解放を対で扱い、Windows側に押しっぱなし状態を残さない。
- ContextMenu、項目、余白、ToolTipを動的なテーマ色で描画。Windows設定の自動追従を維持。
- 外部依存・常時走査を追加せず、dev.1のソースタグと配布物を保持。

## v0.1.0-dev.3
- 既定の右ドラッグ上方向ジェスチャーを廃止し、設定の `MousePattern` でマウス呼び出し方法を1つ選択する。
- 既定の `MiddleThenRight` はホイールボタンDOWNを保留し、動かさずに右ボタンDOWNすると即時呼び出し。`RightThenLeft` は右ボタンを先に押し、動かさずに左ボタンDOWNすると即時呼び出し。ボタン順序を固定し、任意の順序の左ボタンDOWNを監視しない。
- 組み合わせの先行ボタンは、5 pxを超える移動がないまま解放された場合、解放時に通常クリックとして復元する。5 pxを超えて動いた場合は、元のDOWN位置から通常のドラッグへ引き渡す。長押しや判定待ちのタイマーは設けない。既定設定では右ボタン単独操作に介入しない。
- `MiddleClick`、`XButton1`（戻る）、`XButton2`（進む）は各ボタンDOWNで即時呼び出し、他アプリでの同ボタン機能を置き換える。`None` はマウス呼び出しを無効にする。すべてのアプリで干渉がないとは断定しない。
- 自アプリ、上位権限の画面、入力状態を安全に確認できない対象ではマウスパターンを認識しない。Ctrl + Alt + Space など設定済みのショートカットは引き続き利用する。
- `MousePattern` のない旧JSONは、`GestureEnabled` が `false` かつ `MouseChordEnabled` が `true` でない場合に `None`、それ以外は `MiddleThenRight` へ移行する。リンクとカテゴリは維持し、JSON schema versionは1のままにする。
- 検索欄はテーマ色に応じたCaretBrushを明示し、フォーカス枠を表示する。プレースホルダーは空欄かつ非フォーカス時に表示し、入力欄の枠全体をクリックしてフォーカスできるようにする。
- 検索は現在の一覧範囲内に限定する。選択カテゴリではそのカテゴリと子階層、全体では全リンク、お気に入りではお気に入り、最近では最近使ったリンクを対象にする。検索欄のプレースホルダー・ツールチップと結果見出しで現在の範囲を示す。
- 全体・お気に入り・最近使ったリンクを選ぶとカテゴリの強調を解除する。カテゴリの選択表示は、親カテゴリの移動などを含む状態変更と同期する。
- dev.1/dev.2の成果物とソースタグを保持する。

## v0.1.0-dev.4
- 設定に「Windowsへのサインイン時に起動する」チェックボックスを追加する。既定はオフとし、JSONの設定値ではなく現在ユーザーのWindowsスタートアップ登録状態を読み取る。JSONのインポートでは登録状態を変更しない。
- オンの保存時は HKCU の Run キーに固定名 `LinkLauncher` で、`"<実行ファイルの絶対パス>" --background` を登録する。オフの保存時はこの固定名の値だけを解除し、他のスタートアップ項目には触れない。管理者権限や追加依存は不要。
- サインイン後はタスクトレイに常駐し、ランチャー画面を前面に表示しない。Windows側でスタートアップが無効化されている場合はOS設定に従い、過剰な警告を出さない。
- アプリのフォルダー移動や版変更で実行ファイルの場所が変わった場合、新しい場所の実行ファイルから起動して設定を保存すると登録先を更新する。
- パスやURLの貼り付け時、入力全体を囲む対応デリミターを揃った組として取り除く。対応する組は `""`、`''`、`“”`、`””`、`‘’`、`’’`、`＂＂`、`<>`、`＜＞`。組み合わせた入れ子の外側も取り除く。内側の文字列やURLクエリ内の引用符は保持する。絶対パス、HTTP / HTTPS、file の既存受付条件は変えない。
- dev.1/dev.2/dev.3の成果物とソースタグを保持する。

## v0.1.1-dev.5
- 手動起動、ショートカット、マウス操作、トレイ、既存インスタンスへの表示要求で共通の前面化処理を使う。通常の前面化が失敗した場合だけ入力スレッド接続とZ順序操作を試み、接続は必ず解除する。恒常的な最前面設定や疑似Alt入力は追加しない。
- 表示直後に一度だけ再試行し、表示世代を照合して古い閉じる要求・再試行が次の呼び出しへ作用しないようにする。所有するモーダルがある場合はその画面を前面化する。
- 非アクティブ化に加え、表示中の実マウス外側押下を監視する。コンテキストメニュー中に外側クリックがあった場合は保留し、メニューが閉じた後に再判定する。固定中、設定で自動非表示が無効な場合、モーダル・並び替えドラッグ中は閉じない。
- 外側クリック監視は非表示中の対象ウィンドウ照会を行わない。フック内では通知と遅延処理の予約だけを行い、ファイル入出力をしない。呼び出しマウス操作の押下・解放処理を維持する。
- カテゴリは同じ親の中で、リンクは現在表示されている範囲内でドラッグして並び替える。ドロップ先の行の上／下半分で前／後を決め、アクセント線で位置を示す。右クリックメニューにも上下移動を用意する。
- カテゴリとリンクにnullableのOrderを追加し、schema versionは1を維持。旧データの読み込みだけでは書き換えず、並び替え・追加・編集の保存時に従来順を初期化する。保存は従来のバックアップ付き置換を使う。
- リンクは全体で共通の順序を持つ。絞り込み中の移動では表示中のスロットだけを入れ替え、隠れているリンクの相対順を保つ。最近使ったリンクは従来の履歴・検索順を使い、手動並び替えは無効。
- dev.1〜dev.4および正式版v0.1.0の成果物とタグを保持する。

## v0.1.1-dev.6
- 前面化APIの戻り値だけで成功扱いせず、実際の前面HWNDを照合する。呼び出し時は必ずZ順を引き上げ、通常窓は一時TOPMOSTの後にNOTOPMOSTで通常帯の先頭へ戻す。フォーカス取得が拒否されても元の背面位置へ戻さない。
- AttachThreadInputを使う経路を削除。入力キュー接続で他プロセスを待つ処理、疑似Alt送信、恒常的なTopmostを追加しない。
- 表示後の一度の補正も、フォーカスの有無にかかわらずZ順を補正する。所有モーダルがある場合はその画面を優先し、メニュー／並び替え中は補正しない。
- マウス呼び出しで抑止したボタンを全て解放した後にも一度補正する。解放とUI表示の前後関係を要求IDで扱い、UI表示が後でも解放通知を保持する。新しいDownで再試行だけを取り消し、既に受け付けた表示要求は維持する。非表示・別の表示要求・新規クリック後に古い要求が復活しないようにする。
- リンク追加・編集ウィンドウ全域でFileDropをPreviewDragEnter/Over/Dropにより受け、TextBoxの既定処理より先に処理する。存在するファイル／フォルダ1件を正規化してリンク先へ入力し、空の名前だけ補完する。複数件は1つずつの入力を案内し、内部並び替えや文字列のみのDropを受け付けない。
- Drop時に保存・起動をしない。リンク先の種類は従来どおり保存時に判定する。常時タイマー、走査、通信、外部依存を追加せず、dev.5までの配布物とタグを保持する。

## 受入条件
階層ごとに登録でき、検索は現在の選択範囲を保つ。カテゴリ選択中は子階層を含み、全体では全リンク、お気に入り・最近ではそれぞれの一覧内を検索する。
標準の関連付けでファイル・URLを開く。
再起動後も登録内容・設定が保持される。
×とEscで常駐へ戻り、トレイから終了できる。
ショートカットの競合と開けないリンクは日本語で表示する。
サインイン時起動は既定で無効で、チェック状態はWindowsの現在ユーザー用Run登録と一致する。バックグラウンド起動時に画面を前面表示しない。
外側の対応した囲み付きで貼り付けたパスやURLから囲みだけを除去し、内部文字列を保つ。既存のパス・URL受付条件を維持する。
初版は試作。既存ソフトより速いという比較は計測前に断定しない。
