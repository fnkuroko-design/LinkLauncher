# LinkLauncher 初版設計

## 目標
案件や資料の種類を軸に、登録したファイル・フォルダ・Webページを素早く開く。
階層をたどる操作と、階層をまたいだ検索を同じ画面に集約する。

## v0.1.0-dev.1
- C# / WPF / .NET 10。外部UIライブラリなし。
- Windows x64のframework-dependent ZIP。ランタイムを同梱せず、未導入時は公式の導入ページを案内。
- 左側のカテゴリ階層、右側のリンク一覧、上部の全体検索。
- お気に入り・最近使ったリンク。名前、リンク先、タグ、カテゴリ名の検索。
- 登録、編集、削除、カテゴリ追加・移動、ファイルやURLのドロップ。
- Ctrl + Alt + Spaceによる呼び出し。タスクトレイ常駐。
- ライト・ダークの表示はWindowsのアプリモードに自動連動。変更通知で追従し、タイマー巡回なし。
- 右ドラッグ上方向のジェスチャーを既定で有効。任意でCtrl + 右クリックも有効化。
- %APPDATA%\LinkLauncher\library.jsonへ保存。置換前バックアップ。JSON入出力。
- 初期サンプルは専用カテゴリ内。実ファイルを勝手に取り込まない。

## 軽量化
待機中はタイマー・全ディスク索引・ネット通信を使わない。
検索は登録データのメモリ内検索。画面表示時のみ一覧を更新する。
マウスフックは有効な呼び出し方法だけを処理し、ファイル入出力を行わない。
表示時間・メモリ・待機CPUは実測値と目標を区別する。

## v0.1.0-dev.2
- 初期700×440、左164、リンク行32＋間隔1の単行一覧。左欄をたたむと幅を164縮める。
- タイトルと常設説明を圧縮し、リンク先・タグ・メモはホバーで表示。メモありを▤で示す。
- ツリーの全展開固定をやめ、開閉状態をセッション内で保持。選択カテゴリの祖先は表示する。
- 操作メニューを右ボタン解放後に開き、リンク起動は同じ行での左押下・解放が揃う場合に限定。
- 右ジェスチャーの押下・解放を対で扱い、Windows側に押しっぱなし状態を残さない。
- ContextMenu、項目、余白、ToolTipを動的なテーマ色で描画。Windows設定の自動追従を維持。
- 外部依存・常時走査を追加せず、dev.1のソースタグと配布物を保持。

## 受入条件
階層ごとに登録でき、検索は全カテゴリを対象にする。
標準の関連付けでファイル・URLを開く。
再起動後も登録内容・設定が保持される。
×とEscで常駐へ戻り、トレイから終了できる。
ショートカットの競合と開けないリンクは日本語で表示する。
初版は試作。既存ソフトより速いという比較は計測前に断定しない。
