# LinkLauncher v0.1.1

正式リリース（2026-10-08）。承認されたdev.6の機能を正式版にまとめました。

## 変更

- 呼び出し時に通常ウィンドウの先頭へ引き上げ、マウスの呼び出しボタンを放した後にも前面表示を補正します。
- 操作メニューが閉じた後も外側クリックによる自動非表示を再判定します。
- カテゴリ・リンクをドラッグ、または右クリックの「上へ移動」「下へ移動」で並び替えできます。順序はローカルに保存されます。カテゴリは同じ親の中で並び替え、最近使ったリンクは履歴順を維持します。
- リンク追加・編集ウィンドウへファイルやフォルダを1つドロップしてリンク先を入力できます。空の名前だけ補完し、保存ボタンで登録を確定します。
- ZIP内の全ファイルを `LinkLauncher/` にまとめました。アーカイブ名は従来形式の `LinkLauncher-v0.1.1-win-x64.zip` です。

## 導入と更新

Windows x64と.NET 10 Desktop Runtime（Windows x64）が必要です。ランタイムはZIPに含みません。未導入の場合は[Microsoft公式ページ](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0)から導入してください。

旧版をタスクトレイから終了し、新しい場所へZIPを展開して `LinkLauncher/LinkLauncher.exe` を起動してください。データは `%APPDATA%\LinkLauncher\library.json` に保存されているため引き継がれます。スタートアップを有効にしている場合は、新版の設定で「保存」を押して起動先を更新してください。

マウス操作は他アプリの入力と重なる場合があり、管理者権限の画面などで認識できないことがあります。必要に応じてショートカットを使ってください。
