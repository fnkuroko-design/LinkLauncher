# LinkLauncher v0.1.3-dev.10

リンク行にWindowsのアイコンを表示する開発版です。

- EXEはアプリ固有のアイコン、アプリのショートカット（`.lnk`）はWindowsが提供するショートカットのアイコンを表示します。ショートカットに指定した独自アイコンも反映し、Windowsの矢印表示を維持します。
- ファイルはWindowsが提供する当該ファイルのアイコン、フォルダーはフォルダーのアイコンを表示します。
- 表示される行を対象に、専用のバックグラウンドスレッドで取得します。メモリキャッシュは最大256件、待機キューは最大64件です。同じリンクの同時取得をまとめ、リンク編集・JSON取り込み時にキャッシュを更新します。
- Webリンクやアイコン取得に失敗したリンクは従来の種類別記号を使います。存在しないファイルは拡張子に対応する標準アイコンへフォールバックし、ネットワーク上のパスは実ファイルを参照せず種別の標準アイコンを使います。
- ライト・ダーク表示とも元のアイコン色と透過を維持します。行の高さやリンクの操作は変わりません。

常時のファイル走査・監視、Webアイコンのネット取得、アイコン画像のディスク保存は行いません。ユーザーデータの形式や設定値を変更せず、完成済みv0.1.2・dev.9以前の成果物を保持します。Windows由来のアイコン画像は配布ZIPに含めず、使用中の環境から取得します。

配布はWindows x64 / .NET 10 Desktop Runtimeを使用するframework-dependent ZIPです。旧版をトレイから終了し、新しいフォルダーへ展開して `LinkLauncher/LinkLauncher.exe` を起動してください。GitHubへの公開は本作業に含めません。

確認範囲は[検証記録](VERIFICATION-dev.10.md)を参照してください。
