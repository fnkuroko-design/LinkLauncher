# LinkLauncher v0.1.3-dev.11

全体レビューで確認された5件を修正した開発版です。

- 破損データから復旧した後に保存が失敗しても、正常なバックアップを保持します。
- 読み込んだカテゴリの参照ID表記と、空白のみの親カテゴリを統一し、階層表示・編集時のカテゴリ選択を維持します。
- リンク・カテゴリの入力検証と実保存が成功するまで編集画面を閉じず、失敗時は入力内容を保持します。
- 日本語を含む作業先・出力先でも入力補助モジュールをビルドできます。
- 引用符・山括弧・環境変数を含むリンク先にも、起動時と同じ正規化を使ってアイコンを取得します。

dev.10のアイコン表示と既存の呼び出し操作を維持します。データ形式は変更しません。今回の修正で入力フックやマウスの押下・解放処理は変更していません。

配布はWindows x64 / .NET 10 Desktop Runtimeを使用するframework-dependent ZIPで、ランタイムを含めません。旧版をトレイから終了し、新しいフォルダーへ展開して `LinkLauncher/LinkLauncher.exe` を起動してください。完成済み旧版・登録データを保持し、比較時は設定を保存せずスタートアップ先を変更しないでください。
